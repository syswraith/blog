# Problem
[3718. Smallest Missing Multiple of K](https://leetcode.com/problems/smallest-missing-multiple-of-k/description/)

# Logic

- Insert all elements of `nums` into a `std::set` to remove duplicates and enable set operations.
- Store the initial size of the set in a variable `length`.
- Iterate through positive multipliers $i = 1, 2, \dots$:
  - Insert $k \times i$ into the set.
  - If `st.size()` changes (is not equal to `length`), then $k \times i$ was not originally in `nums`.
  - Return $k \times i$ immediately as the smallest missing multiple.

# Code

```cpp
class Solution {
public:
    int missingMultiple(vector<int>& nums, int k) {
        set<int> st(nums.begin(), nums.end());
        int length = st.size();
        
        for (int i = 1; i < 102; i++) {
            st.insert(k*i);
            if (st.size() != length) {
                return (k*i);
            }
        }

        return k;
    }
};
```
