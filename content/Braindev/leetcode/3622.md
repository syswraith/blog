# Problem
[3622. Check Divisibility by Digit Sum and Product](https://leetcode.com/problems/check-divisibility-by-digit-sum-and-product/)

# Logic

- Extract digits of `n` using `% 10` and `/ 10` while iterating through a copy of `n`.
- Track the sum of digits in `digitSum` (initialized to `0`) and the product of digits in `digitProduct` (initialized to `1`).
- Calculate the combined `divisor = digitSum + digitProduct`.
- Guard against division by zero (`divisor == 0`).
- Return whether `n` is divisible by `divisor` (`n % divisor == 0`).

# Code

```cpp
class Solution {
public:
    bool checkDivisibility(int n) {
        int nc = n;
        int digitSum = 0;
        int digitProduct = 1;

        while (nc != 0) {
            int digit = nc % 10;
            nc /= 10;

            digitSum += digit;
            digitProduct *= digit;
        }

        int divisor = digitSum + digitProduct;

        if (divisor == 0) {
            return false;
        }

        return (!(n % divisor));
    }
};
```
